# Draft 隔离

Draft 用于暂存笔记、实验材料，以及跨 Agent 或设备交换文件。可按需创建、保留和删除；正式内容应能独立于 Draft 使用。

## 命名与边界

- 文件用 `x.draft.y`（如 `memory.draft.md`），保留真实扩展名。
- 目录、Git 分支及仓库名以 `.draft` 结尾（如 `research.draft/`、`review.draft`）。
- 目录或仓库内的文件属于该 Draft；显式嵌套的 Draft 有独立边界。

## 隔离

- **Draft 边界外的持久内容不得引用或依赖 Draft 内部内容**，包括其他 Draft；文档链接、代码导入、构建、测试、配置和工作流中的直接或间接依赖均在此范围内。
- Draft 内可以引用自身及正式内容，但独立的 Draft 之间不得建立引用或依赖。
- 可以临时读取、检出或运行 Draft，并将成果复制、改写或整合进正式内容；整合后的成果须独立成立。
- 隔离约束的是**持久引用和依赖**。普通 Git 提交祖先关系不视为 Draft 引用。
